# Hobby project imagery

## Fitz Roy photograph

`fitz-roy.jpg` is the original 2048×1536 photograph **Fitz Roy 2.jpg** by
Prissantenbär, taken 19 March 2005. The creator released it into the public domain.

- Source and rights: https://commons.wikimedia.org/wiki/File:Fitz_Roy_2.jpg
- Original: https://upload.wikimedia.org/wikipedia/commons/7/7a/Fitz_Roy_2.jpg
- Retrieved and visually verified: 9 September 2026.
- Shows: Fitz Roy's granite towers and snowfields in Patagonia.
- Unmodified source bytes; the website crops responsively using object-fit.
  Next.js generates delivery sizes. This is a photograph, not a terrain render.

## Ascenso

`ascenso-lanin.webp` is Ascenso's existing cover artwork for Volcán Lanín,
copied from the project-owned `public/ascenso/art/cover-lanin.webp` in the jtreks
repository. Visually checked before reuse. It is presented as game artwork,
not documentary photography.

Hermes Thrice and the notification/event previews are code-native illustrations.
They do not claim to be live data, recordings, or screenshots of a running app.
